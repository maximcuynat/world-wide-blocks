# Device sheet: 5-port desktop switch (`desktop_switch_5`)

**Family signature "desktop switches"** (guide, section 5): a **flat slab**, light plastic, 1 px high; the **whole front taken by RJ45 ports** recessed 0.5 px; the **LEDs on the top**, along the front edge, one above each port, the power LED at the left end; vent dots on the top, rubber feet drawn underneath, the power input at the back. An internet box is the opposite: standing, with a glass band and its ports low on its front. The 8-port switch (`desktop_switch_8.md`) is the same family, wider and deeper.

Status: rough draft approved by Max on 2026-11-20; **final version chosen by Max on 2026-11-20** (preview `switches_scene`, `switches_fronts`): the same elements, the contacts drawn on the floor of the holes too (guide, section 5). Not exported: the block, its blockstate, item, Java shape and language keys come with lot 1d-1 (issue "Desktop switch, 5 ports"). Generated by `design/tools/desktop_switches.py` (never saved from Blockbench so far).

## Size

- Real: ≈ 100 x 75 x 25 mm, provisional value, not verified (status M, `docs/network-equipment.md`; depth reduced from 100 mm on 2026-11-20).
- In game, x 2.4: 3.8 x 2.9 x 1.0 px, rounded to **4 x 3 x 1 px**. Envelope from 6, 0, 6.5 to 10, 1, 9.5.
- No plinth and no cover bevel: at 1 px high there is no room for them; highlight and shadow lines on the sides, rubber feet drawn under it.
- Java shape for lot 1d-1: `Block.box(6, 0, 6.5, 10, 1, 9.5)` for a front facing north, turned with the orientation (4 x 3 footprint).

## Elements and texture

- `case` (6, 0, 7 to 10, 1, 9.5) behind a front panel 0.5 px thick split around the 5 ports (`front_top`, `front_bottom`, `front_middle_1` to `_6`), as on the box (`RecessedFront`).
- 64 x 64 sheet, 4 texels per px, colours of the palette only: top 0, 0 (16 x 12), bottom 32, 0, front 0, 20 (16 x 4), back 32, 20, sides 0, 28 and 20, 28 (12 x 4), hole ceiling 0, 36, floor 0, 40 (16 x 2), hole sides 32, 36 (2 x 2).
- Ports: RJ45, the single size (2 x 2 texels), pitch 3 texels, 1 texel of margin on each side (the 16 texels of the front). Bottom in socket shadow tone with the contacts row at the bottom, contacts on the back row of the floor of each hole; ceiling and sides in socket colour.
- Top: power LED and the 5 port LEDs on row 1 (the front is full, guide section 5), 6 x 3 vent dots behind.
