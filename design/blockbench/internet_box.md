# Device sheet: internet box (`internet_box`)

**Family signature** (guide, section 5): a **standing** case, light plastic; a **black glass band standing out of the top of the front**, set back from the side edges; **4 recessed LAN ports low on the front**, an LED above each. A desktop switch is the opposite: a flat slab, the front taken by the ports, its LEDs on the top.

Follows `docs/design-guide.md`. Status: version 3, chosen by Max on 2026-11-20 (preview `round3_inset05`), exported to the assets with `design/tools/export.py`; build green and checked in game by Max on 2026-11-20 (four orientations with the turned shape, cable start, front, inventory, hand, ground, frame, box placed before the change, no model error in the log). Generated by `design/tools/internet_box.py` (never saved from Blockbench so far).

**Ports of 2 x 2 texels, chosen by Max on 2026-11-20** (previews `box_2x2`, `rj45_box_close`), exported the same day: the LAN ports and the line input go from 3 x 3 to 2 x 2 texels, the single RJ45 size of the guide; the LAN contacts are drawn on the bottom row of the back of each hole and on the back row of its floor, the only option that shows from the front, from above and from the side. Build and game tests green on 2026-11-20 (`BlockResourcesTest`, 36 game tests); not looked at in game yet.

## History

- Version 1 (flat 7 x 7 x 3, one element, painted ports): approved in Blockbench on 2026-11-19, checked in game on 2026-11-20 (commit 401a922).
- Version 2 (flat 7 x 7 x 3, plinth, cover bevel, recessed ports): checked in game on 2026-11-20 (commit 12b76a6), then its approval was withdrawn the same day: it looked like a desktop switch. Its dark variant stays in `archive/internet_box_dark.bbmodel` (flat version 2 design, for a possible colour option).
- Version 3, ports of 2 x 2 texels (2026-11-20, see the status): single RJ45 size; holes moved by one texel (7 texels left on each side), LEDs above the left texel of each port.
- Version 3: tracks compared side by side with the switch (`preview.py --scene`): A (ports at the back), B (flat, dominant glass band, stepped top), C (standing). Max chose C with the glass band of B as a step out of the front (reading 2 of "the second stage of B"), set back 0.5 px from each side edge so that it never runs over the sides (0.25 px looked flush with the outline in a 3/4 view).

## Size

- Real: the case of 183 x 183 x 80 mm (status E, `docs/network-equipment.md`), standing: 183 wide, 80 deep, 183 high.
- In game, x 2.4: 7.0 x 3.1 x 7.0 px, rounded to **7 x 3 x 7 px**, glass band included in the depth.
- Java shape: `InternetBoxBlock.SHAPES`, `Block.box(4.5, 0, 6.5, 11.5, 7, 9.5)` for a front facing north, turned with `Shapes.rotateHorizontal` (90, 180, 270 degrees for east, south, west, as the `y` of the blockstate).
- Light plastic (guide, section 4: home devices); this also sets the colour of the desktop switches of lot 1d-1.

## Placement of the ports

- **4 LAN ports on the front, line input and power socket at the back.** The front turns toward the player who places the box (`InternetBoxBlock`, FACING opposite to the player's look), so the ports where the room's computers plug in are in sight; the line goes to the back, toward the wall where it will arrive at lot 3. **A choice of playability, made on purpose against the realism of a real box** (Max, 2026-11-19).
- Relief on the front only: the LAN ports are holes 0.5 px deep; the back, which faces the wall, keeps painted ports (Max, 2026-11-20, guide section 5).
- The power socket is drawn now, although nothing uses it before lot 1e (electricity).

## Known limit

The cable is attached at a fixed height of 0.3 block (4.8 px) at the centre of the block, for every device (`CableRenderer.ATTACH_HEIGHT`): on this standing box it comes out of the middle of the case. Not changed with this design; judged acceptable by Max in game on 2026-11-20.
