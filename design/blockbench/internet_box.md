# Device sheet: internet box (`internet_box`)

Follows `docs/design-guide.md`. Status: version 2, light body, chosen by Max on 2026-11-20 and exported to the assets with `design/tools/export.py`; build green and checked in game by Max on 2026-11-20 (four orientations, recessed ports from the front and at an angle, plinth and bevel, inventory, hand, ground, no model error in the log). Generated by `design/tools/internet_box.py` (never saved from Blockbench so far). The dark variant is kept in `archive/internet_box_dark.bbmodel` for a possible colour option.

History: version 1 (one element, painted ports, black vent slots) was approved in Blockbench on 2026-11-19 and checked in game on 2026-11-20 (commit 401a922); Max then asked for a cleaner design and for ports with real depth.

## Size

- Real: 183 x 183 x 80 mm (status E, `docs/network-equipment.md`).
- In game, x 2.4: 7.0 x 7.0 x 3.1 px, rounded to **7 x 7 x 3 px** overall. The Java shape (`InternetBoxBlock.SHAPE`, 4.5 to 11.5, 0 to 3) is unchanged: every element stays inside it.
- Body in light plastic (guide, section 4: home devices); this also sets the colour of the desktop switches of lot 1d.

## Placement of the ports

- **4 LAN ports on the front, line input and power socket at the back.** The front turns toward the player who places the box (`InternetBoxBlock`, FACING opposite to the player's look), so the ports where the room's computers plug in are in sight; the line goes to the back, toward the wall where it will arrive at lot 3 (optical or telephone socket). This is the split already written in `InternetBoxBlock`. **A choice of playability, made on purpose against the realism of a real box** (decided by Max on 2026-11-19).
- A real box has all its ports at the back. Alternative set aside: everything at the back as in reality, with only the LEDs on the front.
- Relief on the front only: the LAN ports are holes 0.5 px deep; the line input and the power socket stay painted on the back, which faces the wall (decided by Max on 2026-11-20, guide section 5).
- The power socket is drawn now, although nothing uses it before lot 1e (electricity).
