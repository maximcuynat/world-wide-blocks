# Security policy

## Supported versions

Only the latest published version (alpha, beta or release) receives security fixes. While the mod is 0.x, a fix may ship in a new version rather than as a patch of the old one.

## Reporting a vulnerability

**Do not open a public issue** for a security vulnerability.

Use GitHub's private reporting:

1. Open the repository's **Security** tab.
2. Click **Report a vulnerability**.
3. Describe the issue: mod, Minecraft and NeoForge versions, steps to reproduce, observed effect (server crash, forbidden player action, data read or changed…).

The report is only visible to the maintainer. There is no contact e-mail address: please use this form only.

## In scope

The server decides everything and the client only displays. Examples of vulnerabilities:

- a modified client that crashes or heavily slows down a server (network packet, cable, device);
- a player acting on devices, cables or data out of their reach;
- a world save that a third party can corrupt.

## What happens next

The mod is maintained on a volunteer basis: there is no guaranteed response time. You will get an answer in the report thread; once the fix is released, the issue may be described in a GitHub security advisory, crediting you if you agree.
