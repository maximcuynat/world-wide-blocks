Title: Terminal screen on the PC tower and the laptop
Labels: type: feature, area: interface, priority: high
Milestone: lot 1c

A right click on the tower, or on the open laptop, shows a command prompt.

- [ ] Screen with a command line and a scrolling output, opened by the server, commands run on the server
- [ ] Laptop: right click opens the terminal; the screen opens or closes by clicking the screen part of the model (sneak + right click with an empty hand is taken by unplugging a cable end, lot 1a)
- [ ] Commands follow the Linux convention (`ip addr`, `ping`, later `traceroute`, `nslookup`)
- [ ] Texts in both language files
