Title: Bridge mode for a box behind another box
Labels: type: idea

Idea from the maintainer (lot 1c-1): a box whose DHCP server is turned off keeps 192.168.1.1, so two boxes chained on one network share that address (`chain` scene). A real box placed behind another one is set either to another address of the network or to a bridge mode with no address of its own on the local network, and then only switches the frames.

Choices to make: a setting of the box (address, or bridge mode), what its status panel shows, whether turning its DHCP server off proposes the bridge mode, and how it fits with the configuration of the devices (idea "Configure the devices like real ones").
